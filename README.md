# claude-web-blueprint

Reusable full-stack starter. Clone, rename, build.

**Stack:** Next.js 16 (App Router, TS) · Tailwind CSS 4 · shadcn/ui · Express + TS · Supabase (Auth + Postgres) · pnpm workspaces.

**Bonus:** ships with a Claude Code bootstrap — one meta-skill (`/adapt`) that reads `projectscope.md` and rewrites `CLAUDE.md` + project-specific agents and skills to fit whatever you're building.

## Layout

```
.
├── frontend/   Next.js 16 app (port 3000)
└── backend/    Express API (port 4000)
```

## Prerequisites

- Node `>=20`
- pnpm `>=9`
- A Supabase project (free tier fine): https://supabase.com/dashboard

## Setup

```bash
# 1. install all workspace deps
pnpm install

# 2. configure env
cp frontend/.env.local.example frontend/.env.local
cp backend/.env.example backend/.env
# fill in SUPABASE_URL, ANON_KEY, SERVICE_ROLE_KEY in both files

# 3. run dev (frontend + backend in parallel)
pnpm dev
```

Visit:
- Frontend: http://localhost:3000
- Backend health: http://localhost:4000/health

## Example flows wired

- `/` landing
- `/login` email + password sign in / sign up (Supabase Auth)
- `/dashboard` server-gated layout, redirects to `/login` if no session, calls backend `/me`
- `/settings` placeholder protected page

Backend:
- `GET /health` public
- `GET /me` requires `Authorization: Bearer <supabase-access-token>`

## Build

```bash
pnpm build
# frontend -> .next/
# backend  -> backend/dist/
```

## Deployment notes (per clone, not pre-configured)

- Frontend → Vercel (zero config) or self-host with `pnpm --filter frontend start`.
- Backend → Render / Fly / Railway / any Node host. Build: `pnpm --filter backend build`. Start: `node backend/dist/index.js`.
- Set Supabase Auth redirect URLs to match your deployed origin.

## Customize for a new project

1. Clone this repo into a new directory.
2. Update root `package.json` `name`.
3. Delete or modify example pages under `frontend/src/app`.
4. Add your own routes under `backend/src/routes` and mount in `backend/src/index.ts`.
5. Add tables to Supabase, generate types: `pnpm dlx supabase gen types typescript ...`.

## Claude Code setup

The repo seeds Claude Code with a single meta-skill that boots the rest of the
config for whatever project you're building.

```text
.claude/
├── skills/adapt-project/SKILL.md   # the only shipped skill
├── commands/adapt.md               # /adapt slash command
├── templates/                      # source of truth — edit these to change output
│   ├── CLAUDE.md.tpl
│   ├── agents/{code-reviewer,feature-planner,stack-specialist}.md.tpl
│   └── skills/{conventions,feature-scaffold}/SKILL.md.tpl
├── agents/                         # generated by /adapt
└── skills/                         # plus more generated by /adapt
```

To use:

1. Edit `projectscope.md` at the repo root — fill in name, pitch, domain, key entities, etc.
2. In Claude Code, run `/adapt`.
3. The `adapt-project` skill rewrites root `CLAUDE.md` and generates
   `.claude/agents/*.md` plus `.claude/skills/*/SKILL.md` from the templates.
4. Re-run `/adapt` any time `projectscope.md` changes. Templates are never
   overwritten; only generated files are.

To change *what* gets generated (different sections, different agents), edit
the `*.tpl` files under `.claude/templates/`.
